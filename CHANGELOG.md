# Release v0.4.0

- Adaptation to regent-sdk 0.13.0

## Installation & Update

### Debian
Download the `.deb` package and install it using:
```bash
sudo dpkg -i ./reg_<version>_amd64.deb
```

### Red Hat
Download the `.rpm` package and install it using:
```bash
sudo rpm -ivh ./reg-<version>.x86_64.rpm
```
